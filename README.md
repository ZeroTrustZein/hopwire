# AegisGraph

Real-time graph AML and transaction monitoring engine, self-hostable in-VPC.

- Cycle, mule fan-in, rapid pass-through, fan-out, velocity and shared-identifier detection.
- In-memory time-windowed graph in Rust; no external graph database needed.
- Bounded BFS with hub tagging and degree caps to prevent supernode latency spikes.
- Every alert carries the payment path that explains it; tamper-evident hash-chained audit log.
- Performance: see [`bench/report.md`](bench/report.md) (generated by `aegis-bench`; no figures are claimed until it exists).
- BSL 1.1 source-available core; see `LICENSE`. Commercial enterprise modules live in `ee/`.

## Architecture
- `crates/aegis-core`: in-memory graph, detectors, scoring arbiter (zero IO).
- `crates/aegis-server`: axum HTTP API, Postgres state, audit log ([API](docs/api.md)).
- `crates/aegis-bench`: benchmark harness (IBM AML dataset) and partner replay tool.
- `console/`: React + Cytoscape investigator UI.
- `deploy/`: Dockerfiles, Compose stack, Helm chart.
- `ee/`: enterprise modules (SSO, automated SAR filing, consortium risk).

Details: [`docs/architecture.md`](docs/architecture.md). Pilot runbook: [`docs/pilot.md`](docs/pilot.md).

## Quickstart
Full stack (needs Docker):
```bash
cd deploy
cp .env.example .env        # set AEGIS_API_KEY and POSTGRES_PASSWORD
docker compose up -d --build
```
Console: http://localhost:3000 (log in with `AEGIS_API_KEY`). Engine API: http://127.0.0.1:8080.

Development:
```bash
cargo test --workspace
cd console && npm ci && npm run dev
```
